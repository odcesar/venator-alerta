# Venator · alerta de inscrito

Alerta para OBS: o Venator dispara o Gutshot (knockback) com fogo e solta uma fala do Ira Domini sorteada, com a legenda em português.

- Teste no navegador: https://odcesar.github.io/venator-alerta/?teste=1
- No OBS (fonte de navegador, repetindo sozinho para ajustar): https://odcesar.github.io/venator-alerta/?auto=10
- Para disparar a cada inscrito: widget personalizado do StreamElements com os arquivos da pasta `streamelements/`.

Projeto de fã, sem afiliação com a Valve.
